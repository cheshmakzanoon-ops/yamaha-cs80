# Minimal SDK workload bridge: no execution/orchestrator

`makeWorkloadCasePlan(case, const InjectedInstance&)` is the concrete owned-session entry point. It requires a successful Connected-phase metadata capture, then consumes `connectedParameterRoster()` from that same enumeration. Complete workload ID admission is performed before any descriptors are returned. The internal `workload_detail::planFromRoster` seam is structural-only and used by inert fixtures; calling it with arbitrary metadata is not native provenance.

One case plan contains only existing `SynthSetup`, `FlushProtocol` (initial and alteration), and `RenderProtocol`. There is no parallel initializer, renderer, serializer, runtime driver, CLI or trigger. Private manifest mode offline1 is explicitly switched to SDK kOffline2, never cast; Invalid manifest enum values are rejected. The two enums have different domains; callers must not reinterpret an SDK enum as a manifest enum.

Initial flush uses the entire generated Params.h control roster plus both Panel13 controls, ordered exactly as the pure manifest. Alteration flush uses exactly two source-derived IDs in this order: volume physical0.22f and ch1_lpf_cutoff physical1200Hz, using the same float normalization. Both are checked against the complete supplied native ID roster; `expectedIds` is built from the frozen intended control identities. `RenderProtocol.parameters` is empty: initial/alteration controls belong to their separately encoded flush descriptors, not hidden audio-frame changes.

Manifest notes map to absolute `TimedEvent.frame`; SDK Event fields are canonical: sampleOffset0 (renderer later rebases it), bus/channel0, flags/ppq/tuning/length0, pitch/noteId48+n, velocity0.75/0. Events remain ordinary note-on/off, with no legacy-output-only CC input convention.

Use existing `encodeFlushProtocol` and `encodeRenderProtocol`. The bridge introduces no new binary format. The existing renderer sets `projectTimeSamples=0..4095` for **each separate segment call**. This bridge explicitly adopts that segment-relative timeline. It does not claim consecutive transport or reset of DSP history, and does not assert A equals restored C/D/E.

Inert tests verify all108 descriptor mappings and mode conversion, full initial and exact alteration rosters, every note field, existing serialized determinism, missing metadata and duplicate extra IDs, plus concrete public-wrapper rejection before Connected metadata and after an actual fake enumeration lacking workload IDs. They compile against pinned SDK headers and Params.h only; the included initializer fixture uses an injected fake loader, never dlopen. No real plugin or processor is invoked. Compiler/libm provenance remains necessary before real-arm equality claims.

The initial/alter flush descriptors do not themselves authorize a flush in any phase. Later driver code must use the already reviewed owned processing-operation gate and make bridge errors terminal. Full A/B/C/D scheduling remains unimplemented. Fresh-module E remains blocked on a reviewed externally bound A-state transfer path. The current split initializer/Connected roster is a dependency under review, not a claim that the entire real observer path is ready.
