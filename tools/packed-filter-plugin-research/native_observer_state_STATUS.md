# Explicit native state contract: preparation only

`native_observer_state.hpp` is separate from the earlier generic `captureState` helper. It never loads a module. The explicit policy is frozen before calls, not selected after a failure. Component state requires success and nonempty complete bytes. Supported controller state requires success (an empty supported stream is allowed). The pinned JUCE policy instead requires exact `kNotImplemented` and zero stream bytes, without stream errors; this is recorded as unsupported, not fabricated successful state. Other failures, exceptions and unexpected output are rejected.

Pinned source evidence (SHA256 matched the authentic preflight dependency manifest): `JuceVST3EditController` inherits SDK `EditController`, without overriding getState/setState. SDK `vsteditcontroller.cpp` lines60–68 returns kNotImplemented. JUCE's supported setComponentState (wrapper lines1194–1230) synchronizes normalized controller parameters from the connected processor and emits restart flags. Component setState/getState are separately implemented at3037/3084. Source identifiers/hashes are in the provenance receipt; source bytes are not bundled.

Restore order is component.setState, controller.setComponentState on an independently rewound copy of the exact component stream, then controller.setState only for the Supported policy. Each return/exception and final stream bytes are retained. Mutating the input stream or hiding stream errors fails. The helper does not require total stream consumption: the pinned controller synchronization intentionally ignores stream contents. It never invokes the known-unsupported controller.setState. Capture/restore are single-use receipt objects; external orchestration must make any attempted retry terminal.

The caller must establish the correct UI thread, initialized/connected objects and stopped/deactivated restoration phase, same source/runtime/bundle, bounded subprocess timeout and terminal ledger. These are not inferred from duck-typed interfaces or receipt fields. Caller-owned receipts preserve ordinary API failure/exception evidence; allocation failure, native crashes or hangs require external logs. This does not restore RNG/oscillator/delay histories or prove any within-arm PCM reset equality. Compare matching complete histories across arms.

25 compiled inert controls cover supported/unsupported/empty streams, unexpected statuses, hidden stream failure, exceptions, exact restore ordering/rewinds, mutation, early stop and retry. They do not prove real JUCE runtime compatibility, thread pumping, state serialization determinism, or plugin qualification. No launch entry point is supplied.
