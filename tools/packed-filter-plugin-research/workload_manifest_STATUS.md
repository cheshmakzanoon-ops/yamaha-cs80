# Workload manifest: proposed data only

This header-only preparation component creates108 exact case records: Legacy/Circuit/PURE ×44100/48000/96000Hz ×realtime/offline ×8/16 sounded notes ×64/256/1024-frame blocks. It neither loads a module nor calls an SDK interface, controls flush, renderer, or synthesizer.

`cases()`, `controls(case)`, `events(case)` and `encode_draft(case)` produce deterministic data. Controls begin with the complete `cs80::defaultValues()` table and use the existing native fixture's float normalization before promotion to double. Overrides: source_performance/parity_mode=(0,0)/(1,0)/(1,1); voice_mode physical0/1 (normalized0/0.25); drift/voice_dispersion/analog_noise=0; volume0.11; tuning_mode0. Default oversampling remains physical1 (normalized0.5). Both appended hardware_source IDs select Panel13, normalized1. The original complete table and fixture hashes are checked before the inert C++ test compiles, and included in each encoded draft.

`bind_native_ids(case, metadata)` regenerates the entire control list internally: callers cannot satisfy admission with a subset. Every generated name/ID must be unique, every supplied native metadata ID must be unique (including IDs not used by this workload), and every generated ID must be present exactly once. Supplied metadata count must agree with its vector length. **Metadata completeness, authenticity and its association with a sealed module are external prerequisites.** Synthetic metadata in the fixture is a negative/positive unit test, not native discovery.

The proposed note cohort has4096 frames: note-on at17+n, note-off at3072+n, pitch/noteId48+n, event bus0, channel0, velocity0.75/0, for n=0…voices−1. Events are in absolute segment-sample order. The eight-voice case intentionally sounds eight notes rather than the original base automation fixture's two-note capacity probe. There is no claim that this is a CPU-study workload or that physical durations match between sample rates.

Encoding is fieldwise fixed little-endian (length-prefixed ASCII strings, unsigned32 case/control/event fields, IEEE754 binary64 normalized controls, binary32 event velocity), not padded C++ memory. Schema marker `packed-filter-workload-draft-v1` and both frozen source SHA256 values precede the case. The executable fixture checks all108 unique case tuples/encodings, every unchanged default, voice-mode normalization, all note events, ID-hash collisions, missing/duplicate metadata, malformed values/cases and byte order. It links no synth-core source/library and performs no synthesis.

This does **not** choose the legal SDK phase or mechanism for applying initial parameters, including zero-frame process calls. It supplies no lifecycle workload, state-history/reset equivalence, pre-setup metrics, latency/PDC/teardown proof, or production qualification. Initializer/renderer integration, deterministic lifecycle semantics and native metadata binding require separate review before any real observer run.

The manifest `Mode` is a private encoding: realtime0/offline1. **Do not cast it to VST3 ProcessModes:** pinned SDK kOffline is2 and value1 is kPrefetch. Any runtime bridge must explicitly switch-map and test both modes. Float normalization uses the frozen source formula but its exact binary output also depends on compiler/libm; their identity must be frozen before comparing real-arm manifests. No cross-toolchain normalization-equality claim is made.
