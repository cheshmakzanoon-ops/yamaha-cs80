# Normal all-target build transaction preparation

The public entry requires the independently frozen 587-row native compile roster,
exact normal production final paths and two filter outputs. It consumes, rather
than creates, the trusted configure/overlay/toolchain/generated-input contract.
No CLI/workflow or implicit build exists. The inner engine is exercised on a tiny
four-object inert CMake project; resulting binaries are never executed.

One normal all-target verbose build per arm supplies the clean enforced relink.
Stock requires absent compiler/final/archive/map outputs. Candidate requires the
complete sealed stock object and link-output copies to equal canonical files
before removing just the two filter objects, core archive and two final/map pairs.
All removals have verified equivalent copies. Every object/final/map/archive path and existing ancestor is checked for symlinks before build or deletion; dangling links do not count as absent. Output, stock seal and source roots must remain disjoint. Actual Ninja command inventory must
match the frozen contract. Filter compile commands match the compile database,
apart from exactly validated Ninja MD/MT/MF dependency switches. Both final links
must contain one exact canonical map option and expected output argument. Required
compile/archive/link actions must each occur exactly once in actual verbose output.

A canonical cross-arm contract digest binds tools, runtime hashes, environment digest (never raw environment values), compile database, Ninja roster/actions, input manifests, targets and paths to the stock receipt. Candidate must match exactly. Archive action binds the frozen ar executable, output and complete core object roster.

An incremental bounded complete build-tree walk rejects symlinks, multiply-linked regular files and special nodes before/after every command, including compiler depfiles and Ninja side-output paths. The cap is frozen in the cross-arm contract; this requires the trusted generated build to remain within the owned nonsymlink tree and is not a race-proof sandbox against hostile concurrent writers.

Sources, complete declared input groups, compile database and runtime bytes are
audited before/after each process. The opt-in exact environment and owned-process-
group checks are used. Postbuild all objects and outputs are copied and rehashed;
candidate may change only the exact filter source and two filter object bytes.
Actual ar listing/member bytes join the normal PIC object to both final ELF/map
proofs. Final source/input/output audits and deadline checks precede admission.
Every failure latches the shared command ledger; partial output is retained.

Still mandatory: independently complete source/generated/tool/runtime manifests,
normal-vs-overlay configure equivalence on authentic production inputs, whole
source/build-tree ownership and quiescence, exact compiler/linker closure, robust
terminal artifact collection and bounded storage. Verbose lines are emitted by
trusted tools, not kernel process tracing. No claim is made against malicious
compilers that forge output or escape their process group. The declared archive
and normal finals are sealed here; complete resources/test binaries/release outputs
must be sealed by the overall arm coordinator before any plugin execution.

No real CS80 configuration, compile, load, original test suite or CPU timing is
exercised by these controls. A-D runtime observer and original-suite transactions
are not yet joined to this build in a launchable complete Stage A entry. Existing
candidate release packaging is deliberately deferred until genuine clean source
commit/CI provenance exists; its original checks are not altered or fabricated.
