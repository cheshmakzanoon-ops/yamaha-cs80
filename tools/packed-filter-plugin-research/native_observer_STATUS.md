# Native observer support checkpoint (not a runnable observer)

This preparation adds only new isolated headers/tests. Original host tests and production source are untouched. There is no CLI, loader entry point, CMake target, workflow or module invocation.

- `native_observer_support.hpp`: fieldwise little-endian integer/float encoding with finite audio/numeric checks; length-prefixed raw bytes and terminated fixed-width SDK text; bounded full binary state buffer; checked ordered closure that continues cleanup after errors and forbids retry. The destructor is best-effort cleanup, not evidence of successful explicit close. Generic cleanup uses preallocated 32 action/result slots and exception_ptr recording; registration may allocate, but closure itself never allocates receipt storage.
- `native_observer_sdk.hpp`: SDK-facing synchronous state streams, serialized component-handler observations (including restart flags), a Created-phase identity cache, separate Factory/Connected/SetupMetrics capture APIs with no legacy mixed fallback, complete bus/ParameterInfo fields, normalized parameter values constrained to [0,1], nonzero bounded class/parameter counts, native latency/tail getters, full raw component/controller state, and explicit ownership-based checked teardown. Actual release counts are recorded but never incorrectly treated as error codes. Native teardown has fifteen fixed receipt slots and no callback/result allocation; raw returned statuses and bounded exception text are retained before acceptance. Ownership flags must be set by a separately reviewed initializer after each successful native call; the header does not prove they were correctly set.
- 15 compiled fake-host support tests pass, including injected allocation failure during closure and a successful closure with all allocations denied. These exercise only host-support code, never a synth or plugin. The SDK adapter passes syntax-only compilation with warnings as errors against 17 headers from official JUCE revision `c352e2489000ffeb9e397051377d75eef2efe641`. Every header SHA256 matches the authentic preflight dependency manifest from run 44123289466. `native_observer_sdk_provenance.json` records those identities and the local compiler. The optional SDK syntax test requires an explicitly supplied `CS80_OBSERVER_SDK`; it skips with a clear reason when unavailable. It never downloads or executes dependencies.

## Important gaps

No native module has been loaded. A separate optional follow-up now compiles/links the adapter and exercises selected methods against in-process SDK-interface fakes (see native_observer_fake_STATUS.md); this is not real-module lifecycle/API conformance. The support/fake executables are not the final native observer.

Still missing: reviewed module/instance initializer and cleanup on every partial-init path; correct handling of combined component/controller objects and connection ownership; full state restore protocol and repeatable DSP history reset; event and parameter stream construction; process/render/PCM collection; optional factory2/3 descriptors if required; capability/sample-format observations; per-transition metadata/PDC snapshots and restart-notification semantics; deterministic workload, complete 108-case and output inventories; actual driver linking/provenance and complete integration tests. Callback event ordering is observed under a mutex, not asserted deterministic. Nondeterministic state or callback differences must not be silently excluded.

These pieces cannot admit an arm or substitute for original fixtures/pluginval, and cannot claim native metadata/PDC/lifecycle equivalence. A reviewed orchestrator must bind observations to exact sealed module bytes, preserve complete resources and process exits, and independently enforce full normal tests.

## Phase and bus gates

CreatedIdentity caches the component CID and explicit combined/separate controller identity before initialization. Connected metadata serializes that live-component-bound cache and never queries controller CID or metrics. SetupMetrics contains only latency/tail and requires an explicit Setup checkpoint. These phase arguments are declarations, not proof: the unimplemented trusted initializer must bind them to successful API receipts. Fake phase guards independently reject late identity queries and early metrics, including forged phase arguments. No metrics observation is fabricated before setup.

NativeOwnership exposes busDeactivationGateRequired=true. It does not yet record or deactivate successfully activated buses. Its accepted flag reports only the explicit existing close schedule; a completed real observer must add checked per-bus deactivation receipts in the correct phase before any admission. Full initialized ownership, correct Handler/host-context lifetime, factory selection and successful setup still require the reviewed initializer.
