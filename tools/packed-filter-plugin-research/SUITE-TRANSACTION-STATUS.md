# Original-suite transaction preparation

This joins the existing frozen roster, exact definition-to-argv binding, per-case
CTest scheduler, JUnit and same-attempt dashboard exit checks, native capture
sealing and cross-arm comparison. There is no CLI, workflow, launch approval or
production admission. The public entry requires all 569 original cases and the
source-bound 294 native cases, not a caller-selected subset. The internal entry
exists to test orchestration with real inert CTest processes.

Before any inventory process, frozen source/script, tool/executable, module,
definition bytes and complete inventories are checked. Definitions must use the
observed literal generated subset, with in-inventory subdirectories, not arbitrary
CMake commands. Hooks and inherited CTEST settings are rejected. Audits repeat
around processes; source identity also repeats around the per-case transaction.
An explicitly frozen replacement environment is hashed with canonical JSON.
Existing Commands callers retain their default merged environment behavior.

Each original case is selected exactly once, with independent exact one-case
inventory evidence, original properties, ordered shared build state and fresh
JUnit/dashboard/log files. Verified equivalent retained copies precede retirement
of generated overlapping evidence. Regex-masked first-attempt nonzero exit and
skips are rejected, not retried. Capture files are sealed and candidate copies
compared with stock copies. No extra invocation substitutes for original exit.

Global deadline checks include sealing/retention and final admission. All errors
latch the shared ledger terminal. Failure diagnostics are best-effort retained
with 64 MiB/file, 256 MiB aggregate and 4096-file caps; truncation is explicitly
recorded and originals remain. This is not yet a complete final artifact pack.

Opt-in Commands process-group checks require the owned group absent after leader
exit; live descendants cause failure and owned-group kill. This is conservative
and can reject unreaped zombies. It is not a cgroup sandbox or proof against a
malicious child escaping its session/process group. The frozen trusted executable
closure must not daemonize/escape; external process supervision remains required.
No idle sample is treated as asynchronous plugin callback quiescence.

Expected manifests, complete dependency/generated-input closure, quiescent owned
nonsymlink build roots, canonical stock/candidate restoration, full object/link
admission and overall artifact/storage/budget authority remain external gates.
Module inventory currently binds file/directory names and file bytes, not full
ownership/mode metadata. Real plugin lifecycle observer, pluginval/release extras,
full build orchestrator and real qualification remain unapproved.
