# Prospective final-artifact evidence

`linkage.py` is read-only. It extracts the actual Engine.cpp.o member from the production core archive and requires byte equality with the frozen candidate object. It checks the real three-argument render ABI `_ZN4cs806Engine6renderEPfiPKf` (including defaulted externalMono), then resolves its object section/offset/size through the GNU live map to the final ELF function. Discarded-only, duplicate/direct/wrong providers, wrong bytes, stale addresses, missing symbols and profile runtime symbols fail. Hidden/local symbol forms are supported explicitly. Raw maps, symbols, archive/object and final binary bytes must be retained.

This checker alone cannot distinguish a stale final ELF whose addresses/sizes coincidentally match. The later orchestrator MUST preserve baseline copies, remove candidate final output and map before an enforced relink, capture the actual verbose link argv and successful exit, require fresh outputs, then bind these receipts and the checker to the new output hash. Every unchanged host/pluginval invocation must use exactly that frozen path/hash, rechecked before and afterward. Remaining full-suite test links must use the unchanged candidate archive. No candidate rebuild/byte change is allowed after qualification begins.

The member/map proof does not establish ownership of every inline/COMDAT header function or plugin CPU benefit. The unchanged real host tests exercise the linked binary; exact capture comparisons cover only their declared outputs. Full release qualification still needs the entire ordinary suite and normal checks. The helper adds no instrumentation and runs no synth/plugin code.

`provenance.verify_compile_scope` accepts explicit frozen CXX and C compiler command paths. The latter is required if any `.c` translation unit appears; C rows are never omitted. The runner must derive paths from CMakeCache, not assume g++, and hash/version-check both resolved driver and internal compiler frontend. Identical strings do not establish compiler identity by themselves.
