# Draft1x research evidence, not a production feature

This directory describes an opt-in approximate rendering experiment. Applying its patch directly to a release is not authorized by this evidence. Existing defaults and parameter/state definitions stay unchanged. No workflow runs these tools automatically. No CPU benefit, plugin qualification or user acceptance is established.

The historical local GNU14.2 functional outcome is in RESULT.md. Raw captures/binaries remain audit artifacts rather than repository payloads. PLAN.md and QUALITY-SUBSET.md state tested and missing coverage. The four-file patch applies to the pinned source tree; source and tests are reconstructed from immutable Git objects, never a dirty checkout.

Explicit reproduction, only when a new functional reproduction is authorized:

```sh
bash run-functional.sh /path/to/repository REVISION /path/to/new-results
```

Requires Bash, Git, tar, patch, GNU timeout, compatible GNU C++20 compiler and Python3 with NumPy. All directories must have trusted/quiescent ownership. The output must not exist; no previous result is overwritten or deleted. CXX may select the compiler executable, not extra flags. Each child command has a300-second timeout (120seconds for the tail fixtures) and no retry. No performance timing is collected. The script builds stock and candidate objects with identical strict flags, retains the special existing IgBatch contraction setting, builds BOTH capture executables plus the structural/followup executables, runs the frozen fourarm scene set and componentimpulse/eighttail fixtures and reducer, and hashes retained files. Do not interpret successful exit as complete instrument quality acceptance.
