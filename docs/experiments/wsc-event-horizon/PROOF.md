# Four-tick WSC event-free certificate (isolated research)

No change to the panel, sound model, quality setting, oversampling factor, residual kernel, public continuation State, event tolerance, or time step is proposed. This is not the previous terminal-node, endpoint-copy, knee-lookup, decay-reuse or vector-width mechanism. It avoids asking the root/turn/knee scheduler at all on a short provably interior run, never delaying a real event or performing a four-tick integration. It does **not** qualify performance until a controlled native CPU comparison succeeds.

## Narrow admission

Exact 96,000 Hz internal rate and normal nominal profile, positive ordinary ramp, zero reset countdown, 16–2048 Hz, prevalidated right-hand nodes, unchanged bit patterns for frequency/comparator threshold, same gates. First source tick after reset/prepare, public restore, copy, idle advancement or any fallback must (re)establish active state. Those operations explicitly clear the private run count. One byte lives next to the bool endpoint-valid flag rather than adding a separate allocation. Every candidate tick rechecks the runtime environment **and** current controls, not only when the token is minted. The WSC remains single-thread-owned like the original. No data racing with a different thread changing environment, oscillator or diagnostics is supported. No shared mutable counter exists in the normal candidate; counters/assertions are separate observer builds only.

Target: ordinary strict GNU/x86-64, no fast-math, FMA, unsafe suboptions or native-only source dependency. Reject unmasked SSE or x87 exceptions, directed rounding, mixed FTZ/DAZ, unsupported x87 control words, and any admission without an already-raised SSE precision flag. Bit classification precedes added FP math to avoid comparing sNaNs/subnormals. Extra operations act on finite, safely bounded normals/zeros. The stock fallback owns *all* public handling of denormal, threshold, NaN, saturation, invalid controls and unusual rates/sets whenever these predicates decline. Private clock invalidation and compiled-code/trap ordering are distinct issues; no device-wide fallback bitwise claim follows from source.

## Why four whole stock steps can be event-free

Let h=1/96000 s, tau=0.1034 s, G<4 the nominal converter gain, f in the range above. Let u be the AC-coupled input and w be the AC-coupled triangle. Admission starts only with |u|,|w|<=8. The interior is a single fixed ramp segment, so p=-Gf, l=triangleGain, |l|<3. The analytic stock segment endpoint uses:

    u_end = p*tau + (u - p*tau)*e
    w_end = (w - B*h/tau)*e, B=l*(u-p*tau)
    e = decay(h/tau).

For h/tau<0.00011, the stock degree-five polynomial is positive, no greater than 1, and |1-e|<=h/tau (allow the explicit numeric margin below). Before certification |u|,|w|<=8. With the bounds used in code, even for 2048 Hz, four steps' upper bounds cannot take either past 16. For each step bound the input by |delta-u|<=h*(4f+160)+1e-8, and conditional on no fold by |delta-w|<=.00011*(16+|l|*(16+4f*.104))+1e-8. Multiply each bound by four to get du,dw. Include the same margin when comparing all initial distances.

One must bound the **discrete production update**, not just its differential equation: the reconstructed pin coming from next charge is equal to pin7 + p*h apart from floating-point anchor/roundoff; the next fold value within one open branch equals triangle + l*(u_next-u) to roundoff. Substituting these relationships into the implemented two-pole state update gives the w endpoint above. The largest intermediate magnitude in the bounded operations is below 6000; the binary64 roundoff per primitive is below 7e-13, with no compensating division by a small state variable in that recurrence. The 1e-8 V allowance per step is intentionally much larger than accumulated nominal update/segment errors. This is a conservative analytic argument for the frozen nominal box, not a machine-checked interval proof for all float data. All boundaries are individually checked in the shadow build by calling the actual stock function before each skipped search.

* Reset: require q>4*(f*h+1e-10). This is larger than accumulated charge rounding plus the stock 2e-15-second physical-end tolerance times f. There can be no physical boundary in the four steps; no elapsed step is shortened.
* Input crossings: keep u outside distance du from each of -rampHalf, zero, +rampHalf, and the exact comparator threshold. Both ends and all interiors are on the same strict side; the stock sign-product tests cannot accept a root, and the stock endpoint proximity adjustment also does not move the branch.
* W shaper knees: require w outside distance dw from all eight nonzero signed quarter-span knots. The small stock sided endpoint/bucket offsets are inside the margin. Do not equate diagnostics.eventCount==0 with no change.
* W turning point: zero l means B=0 exactly. Otherwise use the actual signed B at admission; |B|>2*(|w|+dw)+|l|*du+1e-8 guarantees that on every subsequent interval |B|>2*|w|. Thus stock turn=tau*(w+B)/B lies above tau/2, far outside the four-tick window. An uncertain turn always goes through the original scheduler.
* On each admitted tick, perform the actual old single-step advance, right nodes, elapsed addition, node cache update, diagnostic readout, and per-branch antialias residual accumulation/clear in stock source order; prior delayed residuals remain active, not assumed zero. No pitch, oscillator phase, AA, or gate update is quantized.

## Floating point and limits

The skipped positive-normal reset-time divide, threshold checks, dyadic-knot selection and polynomial scheduler can add ordinary inexact status; this is why the precision flag must already be sticky. Admission comparisons and guard math cannot introduce another condition in the bounded box. The no-crossing condition excludes ln1p/root and long-double fallbacks; they never silently lose an errno or x87 exception here. The moving state still evaluates stock advance/node/output expressions, including original residuals and per-branch floor/sided behavior when those belong to the node computation. An unsupported FP environment takes the stock source, no FP control bits are changed to admit work. Source-level stock dispatch is not automatic proof of identical *machine* trap partial state under alternate flags/toolchains. Exact comparator, right cache, residuals, masks, return/pinned retained events and interruption probes are separate from audio-only testing.

The separately instrumented witness uses the actual production nextBranchEvent and physical calculation. The normal candidate does not execute that instrumentation; both are compared with the matched stock. A deliberately broken omission of the u/w/turn tests must generate witnessed false positives and observable different state. Shapes/rates outside the certificate cannot be claimed faster. Never use an instruction count, occupancy, correctness check or stock hotspot percentage as a native CPU improvement.
