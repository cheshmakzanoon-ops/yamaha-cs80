# Synthetic capped-state cost, not WCET

Frozen baseline is the test-only published 28999229 stage (pre-recovery). Captured warped behavior is the applicable unrepaired baseline; this is not an independently rebuilt 6f71b0a engine benchmark. Repaired scalar and wrapper use current production headers/backend. All sources/binaries/fixture hashes retained in hashes.txt. Compilation: g++ C++20 -O3 -ffp-contract=off, baseline ISA, GCC runtime AVX2 dispatch actually exercised.

512 retained warped capped states, each inserted in lane 0/1/2/3 individually, or all four lanes, plus converging zero-input reset-state controls. Each measurement is one 512-group chunk. Stage restoration, output checksum consumption and finite checks are OUTSIDE the timer. 3 warmup chunks then 31 measured chunks for each variant/scenario, cyclic alternating execution order. Untimed checks prove expected wrapper rejection on capped groups, successful dispatch on all controls, and exact named-memory/output parity with repaired scalar. No mutable production instrumentation. Every timed chunk consumes finite outputs; repaired scalar/wrapper checksums agree.

First run occurred before the parent's hold instruction arrived; preserved as provisional-results.csv and excluded from summary.json. Final results.csv was rerun after explicit compute-idle signal. Logs retain all exit statuses. Timings use steady-clock elapsed time, not thread CPU time. Scheduler interruptions remain visible, especially maxima; this shared environment is not a controlled target device.

summary.json contains per-group chunk-average median and maximum, plus median paired ratios. A chunk-average p99 is NOT an individual-call latency percentile. Worst observed 512-group chunk duration is max_chunk_average_ns_per_group times 512. Synthetic repeated failure workload is not audio-realism, target qualification or theoretical worst-case execution time. No claim that fallback is cheap: additional root work is plainly measurable.

Separate count.cpp diagnostic invokes the captured equations directly with a scratch helper copy differing only by namespace/include and an evaluation counter. All 512 accepted output tuples match the production helper bit-for-bit across bp/hp/t1/t2/residual. It observed 27..37 additional helper equation evaluations (median 35), following the original five failed Newton evaluations. These are equation evaluations, not additional Newton iterations; wrapper also discards its prior SIMD work before scalar retry. Counts are for frozen captured coefficients, not a general bound or trajectory frequency.
