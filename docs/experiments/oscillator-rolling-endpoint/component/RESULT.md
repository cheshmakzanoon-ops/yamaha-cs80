### Oscillator checks

On GNU C++ 14.2, x86-64 Linux (Release, PIC, no fast-math), the sample outputs, continuation state, raw diagnostics and event records matched the unmodified oscillator. The existing differential corpus passed 328,508 checks across 161,787 paired ticks. Its extended floating-point environment harness passed 6,011,358 checks across 970,722 ticks and 1,008,348 paired API calls, with SSE/x87 flags and errno checked. The native-ISA stress build passed the same extended corpus. Five unmodified project CTests passed: cs80_core_tests, cs80_experimental_oscillator_tests, cs80_oscillator_promotion_tests, cs80_filter_batch_engine_tests, and cs80_source_performance_tests.

The separate component timing test used the archived full-object probe at 96 kHz with a per-thread clock as well as a wall clock. All 576 rows (192 same-version, 384 stock/candidate) retained their original order and checksums matched across pairs. Across ten active 16/32-oscillator cases, the balanced-block geometric mean indicated 5.44% lower CPU (95% bootstrap interval 4.29–6.68%). The maximum corresponding same-version aggregate deviation was **9.11%**, above the candidate interval; some per-case lower bounds also crossed the −3% floor. Part of same-version calibration overlapped plugin compilation on other cores. **Do not treat this as a demonstrated component gain.** No reruns or discarded timing rows.
