## Offline root replay

Run python3 replay.py and python3 monotonic.py. All768 captured equations reproduce the logged accepted residual (1e-12 absolute /1e-13 relative check) and find a finite point with original-expression abs(residual)<1e-7. No bracket expansion; at most38 evaluations including original-point check and two endpoints (35 midpoint evaluations). Replay budget is96 midpoint steps, not a production promise. Results and failures are retained in roots.json/root-summary.json; no failures in this corpus.

For every capture: c1>=0,g>=0,ff>=0,level>0; A=1+ff*(c1+ff)>0 finite. Analytic bracket uses B=ff*c0-zBp and C=g*level*(1+ff), endpoints(-B +/- C)/A; original-expression endpoint signs are explicitly verified. monotonic.py uses exact Fraction arithmetic to show derivative numerator of the rational tanh branch has strictly positive Bernstein coefficients on x^2 in[0,4.97^2]. Denominator is positive and clamp jumps are upward (~6.22e-7); hence the ideal real-valued clipped law is nondecreasing and bounded[-1,1]. With captured coefficients the ideal residual is strictly increasing: any exact zero is unique, but a clamp jump can omit zero entirely. This is not a proof of rounded floating-evaluation monotonicity. Acceptance therefore requires actual original-expression residual tolerance, never sign bracket width alone. Captured success does not cover omitted failures or establish a corrected trajectory.
