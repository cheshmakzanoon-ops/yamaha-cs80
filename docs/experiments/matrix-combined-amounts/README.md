# Simultaneous automation of all sixteen matrix amounts

Test-only extension of the isolated-slot 108-lane milestone. The native module,
archive, production sources and all historical contracts/evidence are unchanged.
Two ordinary public-API canonical sessions enable all sixteen routes or none.
Each slot repeats the MSEG(slot modulo 3) to pitch/cutoff/level destination
pattern, targeting both ranks. This is concurrency coverage for that specific
configuration, not general source/via routing qualification.

  within the unchanged 2e-6 host contract.

  above the predeclared 0.00001 minimum.

  and static-zero routed/no-route identity.
- 12 native configuration readbacks and two public canonical roundtrips.
- Four binary identities, eight candidate source hashes and 5,207 retained
  identities verified throughout the staged run.

Histories use two notes, 16,384 stereo frames, manual/manual source mode, proven
unsynced poly-triggered looping bipolar MSEGs, initial amount 0.02, modest signed

Prior isolated-slot tests establish slot identity; this extension checks all-slot

## Limits

These 216 captures are identities, not old/new baseline pairs. No baseline
compatibility, general routing/via, source-mask, sync/shape-edit, full-range,
native DAW, cross-platform, CPU-target or hardware-fidelity claim follows.
Historical suites and Legacy behavior were not rerun here. CMake targets were
source-reviewed only; recorded standalone generator/runner builds were executed.
No production rebuild, broad/malformed-state suite, editor/window, or display/
privilege workaround was used. Original serializer bytes were loaded natively.
PCM/native state files remain in build directories with stage-recorded hashes.
