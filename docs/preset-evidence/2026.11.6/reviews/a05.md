# A05 — Stable piano course geometry

The secondary piano string was retuned on every note: its six partials each
used a new random 0.8–1.5-cent displacement, with alternating positive and
negative signs. The strike seed came from voice age. This changed the
instrument's late resonance and produced a course whose partials did not share
one string detuning.

`InstrumentBody::makeHarmonicModes` now gives that course one stable
+1.15-cent offset, introduced by the existing smooth bass transition. All six
partials share it. The preceding random draws are still consumed, preserving
the independent strike-phase and contact-noise sequences. The authored
stiffness, partial weights/losses, course strength and existing register curves
are unchanged. There are no new parameters, modes, per-sample calculations or
allocations; the course's exponential is now computed once per note.

The separation of string tuning from hammer excitation follows the distinction
in [Bank and Sujbert, DAFx-02](https://www.dafx.de/papers/DAFX02_Bank_Sujbert_piano_synthesis.pdf).
The fixed 1.15-cent amount is an authored choice, not a measurement of a piano.
[Renault, Mignot and Roebel, DAFx-22](https://www.dafx.de/paper-archive/2022/papers/DAFx20in22_paper_48.pdf)
also separate instrument/string detuning from the excitation controls. This
change does not establish acoustic indistinguishability or sympathetic string
coupling.

## Rendered verification

The new `PianoCourseGeometryTests.cpp` measures late audio through two
overlapping Hann-window quadrature projections. It never accesses the private
mode arrays. Frequencies are measured across three strike seeds, MIDI notes
60/72/84, 44.1/48/96 kHz host rates, and a separate 2× internal-rate case.
Attack variation covers MIDI 24/36/60/84/108, while equal-pitch comparisons
probe both sides of the 30/32/47/49/60 register boundaries.

| Measurement | Previous source | Revised piano-only source |
| --- | ---: | ---: |
| Maximum strike-seed frequency spread | 0.56448869 cents | 0.00002798 cents |
| Maximum mismatch between the first two course partial offsets | 2.60575569 cents | 0.00011791 cents |
| Geometry checks | 75 failures / 212 | 0 failures / 212 |
| Minimum attack waveform difference between seeds, relative RMS | 5.663427% | 5.311733% |
| Maximum register-boundary difference, relative RMS | 0.001607% | 0.001611% |

The existing struck-body dynamics regression also passes **3,439 checks**.
Its piano cases preserve monotonic measured fundamental/RMS response and
remain below full scale. These scoped measurements demonstrate stable tuning
with changing excitation; they are not a listening-panel rating.

During concurrent material-model edits, a direct shared-header compilation
encountered the temporarily undeclared `makeMaterialModes` function. The final
scoped runs therefore use an isolated copy of the exact baseline
`c76ad288e02fbeca48f39652bf4fcdd99837f793` plus only this piano patch. The
coordinator must run integrated regressions after all source edits finish.
