## Change

Added one scoped entry in the root `.gitattributes`:

```gitattributes
docs/preset-evidence/2026.11.5/baseline/inventory.json -text
```

This immutable fixture is authenticated by its raw bytes, so Git must preserve
those bytes when checking it out. The rule disables checkout newline conversion
for this exact file. It does not apply to other JSON, source code or guides.

The baseline file, comparator, comparator test, expected digest, factory recipes,
DSP, workflow and CTest registrations are unchanged. Runtime parsing and digest
authentication still reject any changed baseline bytes. No CRLF digest was
added to an allowlist, no test was skipped, and no hash or audio threshold was
relaxed.
