# A13 — Existing material-voice audition roster

## Implemented scope

Extended `scripts/capture-factory-auditions.py` with matched excerpts for nine existing programs: Tubular Bells, Gong, Temple Bell, Agogo, Music Box, Banjo, Koto, Harp and Kalimba. Each is requested at MIDI 48, 60 and 72, at velocities 0.25 and 0.85, with pressure zero, a 3.5-second hold and a one-second release excerpt. The six appended folders are `material-profile-{48,60,72}-{soft,firm}`. Existing program addresses and the preceding 40 folders are unchanged.

The helper retains its existing 48 kHz stereo float, unnormalized export contract, command-line arguments, before/after source and executable checks, inventory admission, render-setting and audio-safety checks, failure manifests and SHA256 checksums. Its generated README describes the additional comparisons. Production inventory handling remains independent of parameter-vector length; the test inventory now carries all 204 parameter IDs and values.
