# A08 — material selection and saved-state contract

Appended `body1_material` / `body2_material` at core indexes **202/203** and
host indexes **308/309**, with ten discrete choices, neutral Standard defaults
and AU version hint **19**. The former model and variant selectors retain their
original ranges and normalized automation meanings. Material selection is
captured by the next accepted note and follows the existing PANEL-only body
policy; it does not enable bodies in electrical hardware-tone or memory paths.

The change includes Engine capture, factory rank swapping/reset, the fluent
recipe helper, host parameters, control-help and typed-value presentation.
Library and UI audits recognize the appended selectors as discrete choices.
No preset identities, addresses, model choices or existing variant choices were
added or changed by this assignment.

Host tests now retain frozen **202-core/308-host** prefixes, exercise all
fourteen body controls through session/user-preset/A-B/undo/factory/MIDI recall,
and require each material to preserve held-note samples while changing the next
note on both ranks. Missing materials in prior states and inactive A/B slots
default to Standard. The capture-metadata contract rejects missing, renamed,
nonstandard and coherently stale 202- or 200-parameter exports.
