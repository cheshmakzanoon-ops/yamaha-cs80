# A36 — control discovery and revised-preset recall

## Finding

The documented path to hearing the revised factory recipe is correct for source
`fcc3c8e055223fe4f786ca162ff46076c33471c8`: open **Library → FACTORY LIBRARY**,
choose the entry, explicitly press **LOAD/RELOAD**, then play fresh notes. No
production correction is warranted by this source and documentation review.

`PresetBrowser::loadEntry` calls `loadFactoryPreset` for factory rows without
an already-loaded short circuit. That processor method applies the current
bank values. LOAD, Enter and double-click all reach this path. Audition's
selection handler intentionally skips an entry already marked loaded, while
REVERT restores the opening sound snapshot. Thus a familiar displayed name or
a highlighted row alone does not establish that an older project's saved
recipe has been replaced. The preset and installation guides explain these
distinctions and advise saving after recall.

## Controls and compatible choices

The host layout exposes **fourteen body controls**, seven per rank. The first
four controls are grouped under Instrument body I/II; Size, Variant and
Material are appended separately to preserve automation order. Each Material
choice uses the same `materialName` function in the host layout and typed-value
formatter. All ten actual labels appear correctly in the guide. The nine
nonstandard profiles map to Bell, Celesta, Tine electric piano, Steel strings
and Nylon strings exactly as documented. Existing factory recipes select the
compatible pairs automatically.

Model, Partial decay, Size, Variant and Material are captured at accepted note
onset. Mix and Brightness remain live. Selecting Model Off does not remove an
already-enabled body; its original onset still owns that body. The renderer
resolves incompatible Material choices to Standard at note onset. This does
not overwrite the stored host selection. The guides also correctly restrict
body excitation to PANEL sources and identify Partial decay as inactive for
sustained bowed, wind, brass and organ modes.

The custom Studio and standalone interface have no dedicated body widgets.
This is disclosed, so players are directed to their DAW's parameter list and
automation editor for individual edits; factory recall remains available in
the regular browser. No claim is made here about a DAW's actual parameter-menu
layout or accessibility rendering.

## Tone buttons and descriptions

All twenty-two original tone-button tooltip/description strings point players
to the corresponding enhanced **Tone I/II** browser name. PANEL and MEMORY
retain their separate behavior. This matches the guide's distinction between
an original electrical tone recipe and the revised named browser voicing.

Reviewed the nine material presets' names, descriptions and tags against the
current inventory. The bell descriptions now explain tube, plate, shell or
comb behavior; obsolete fixed-ring-carrier tags are absent from the five
reprogrammed natural bells. Harp and Kalimba explicitly describe same-pitch
ranks, while Koto retains its intentional initial-bend tag. No new name or
category mismatch was identified. This is a metadata/implementation review,
not a listening assessment or proof of acoustic equivalence.

## Optional documentation polish

Two small clarifications would make manual editing easier without changing
sound or compatibility:

- Use the full host Model labels **Tine electric piano**, **Steel strings** and
  **Nylon strings** in the compatibility table, rather than their abbreviated
  Tine/Steel/Nylon forms. Players can then match the menu literally.
- Add: “An incompatible Material remains selected and saved, but uses the
  Standard sound until you choose its compatible Model and play a fresh
  note.” The existing wording is correct; this makes the display-versus-sound
  distinction explicit. Searching the host list for **Body I material (next
  note)** or **Body II material (next note)** would also be a useful hint.

These are recommendations only; this assignment did not edit the main guides
or the frozen source.
