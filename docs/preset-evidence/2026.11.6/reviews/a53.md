## What the user receives

The outer ZIP contains the compressed installation tree, its external manifest
and `SHA256SUMS`. Both checksum entries match their actual bytes. The installation
tree supplies **INSTALL_AND_QUICKSTART.md**, **PRESET_GUIDE.md**,
**DISTRIBUTION_STATUS.md**, **SOURCE.txt**, the project license, seven third-party
notice/source files, and JUCE provenance. These documents accompany the native
VST3, AU and Standalone bundles; no separate README file is required by this
packaging format.

The installation guide identifies the native **arm64** artifact and all three
formats. Its platform table distinguishes the separate Intel Mac package and
instructs the user to match their host process architecture. It explains keeping
bundles intact, checking the outer checksums, closing the DAW before replacement,
avoiding duplicate plug-in identities in scan folders, and normal rescanning.
Its signing language distinguishes ad-hoc build signatures from publisher
release signing or Apple notarization. The manifest explicitly says that the
packaging helper did not inspect signatures and did not perform release signing
or notarization; this audit does not add a certificate-validation claim.

`SOURCE.txt` and the manifest unambiguously identify the full source commit and
**2026.11.6**. The preset guide states **523 existing programs**, **521 musical
programs**, **204 core parameters / 310 host positions**, and **fourteen saved
body controls**. It directs the player to explicitly **LOAD/RELOAD** the factory
entry and play fresh notes, explains why an already-loaded Audition row may retain
older settings, and distinguishes REVERT from loading the current recipe.

The next-note Model/Decay/Size/Variant/Material controls and live Mix/Brightness
controls are described correctly. Standard fallback for incompatible material
combinations and the absence of dedicated Studio/standalone body widgets are
disclosed. A41 has prepared A36's optional display-versus-stored-selection
clarification and exact full Model labels for the online guide; they are absent
from these unchanged source-time bytes. The earlier abbreviated labels remain
understandable.

## Source-time links and distribution history

The **three packaged guides exactly reproduce the frozen source packager's
link-rewriting output** for the three documents at `fcc3c8e`. Seven local guide
links resolve within the actual installation tree. All **119 source-pinned
repository targets** exist as files in that exact commit; none unexpectedly
points to a directory through a `blob` URL. Two explicitly authored

or fragment links were classified but not fetched over the network by A53.

The bundled distribution history still begins with the **2026.11.5 candidate**
and records the **2026.11.4 publication**. That is the exact historical file
present when this `.6` binary was built, rather than a claim that this archive
contains `.4` or `.5` sound data. The current-download links in both that history
and the preset guide point explicitly to the live README. The installation
guide also tells the reader that later documentation changes do not change
existing archive bytes and that full commit/revision identifiers take precedence
over a shared application version string.

The final publisher should preserve this distinction when the online delivery
record is updated. Replacing the frozen package history in-place would change
the qualified archive. No rebuild or extra release gate is proposed for this
documented source-time snapshot.

## Assets and notices

The nine new material paths are numerical mode tables compiled through
`InstrumentBody.h` and `InstrumentBodyMaterials.h`. The inspected generator has
no external audio/file reader, and the installation tree requires no new WAV,
AIFF, FLAC, SFZ or SF2 sample collection. This is a source-and-package asset
completeness finding, not an independent re-execution of every material voice.

The project license and six repository-owned notice/source files match their
source-commit bytes. The JUCE license matches the local reference checkout
verified at the pinned `c352e2489000ffeb9e397051377d75eef2efe641` commit. This
checks notice inclusion and integrity; it is not a legal opinion or a new license
compatibility assessment.
