# A30 — Installation acceptance helper and `.7` contract

## Decision

Reuse the unchanged `.5` A41 helper for `.7` byte inspection on all four
targets. Its explicit source/revision/run/attempt/architecture inputs and
source-pinned inventory/header checks match the current package format.
No actual package defect was found in the supplied ARM Mac archive.

Two qualifications are required in the `.7` usage contract:

1. The helper verifies the complete declared inventory, but does not require
   all guides/notices or compare them with their source. A source-specific
   supplement now checks the actual ARM package; apply it to each other target.
2. Its historical `remaining_gates` text says 13 validator lanes. The current
   workflow requires **15**: Linux 3, Windows 2, ARM Mac 5 and Intel Mac 5.
   The unchanged helper's prose is not the current qualification checklist.

Both findings were reported to the coordinator and A44. They do not invalidate
the helper's byte checks. No helper, production source, workflow, shared test,
frozen historical evidence or remote ref was changed.
