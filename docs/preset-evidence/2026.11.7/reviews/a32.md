Its artifact check does not establish repository URL identity or independently compare `expires_at` to inspection time. ## Windows notice checkout transform

The coordinator identified a concrete Windows-specific risk in A30's new notice comparison: the packager reads seven repository notices with `read_bytes()`, while A30 requires equality to `git show` bytes. The sole source `.gitattributes` rule protects only the authenticated `.5` baseline JSON. A clean Windows checkout can therefore place CRLF bytes in these notices, and the packager faithfully preserves them. Guides use `read_text()` through `packaged_markdown` and retain their exact source-derived comparison.

An isolated index of the exact `.7` source with `core.autocrlf=true`, `core.eol=crlf` produced **exactly** the complete LF-to-CRLF transform for all seven notices. All seven source blobs are LF-only, contain no CR or NUL, and retain the same contents under the demonstrated checkout conversion. [The transform receipt](../verification/a32/windows-notice-checkout-transform.json) records each source hash/size, transformed hash/size, source attributes and controlled checkout command. This is a local source-checkout demonstration; it does not claim to have read an unlogged CI Git setting or inspected the actual Windows archive.

When the actual archive arrives, first preserve its API/ZIP/member hashes and passing A41 inventory. If A30's raw notice comparison then rejects only this issue, use a **separate Windows-only review**: the seven files must all match the exact source bytes, or all match the one demonstrated full LF-to-CRLF checkout transform. Require the original clean checkout and unchanged package step. Accept no mixed or partial EOL conversions, added/removed newline, changed text, BOM, whitespace adjustment or broader path exception. The transform does not apply to guides, `SOURCE.txt`, provenance, binary/resource payload comparison, Mac/Linux packages or arbitrary files. Do not edit A30's accepted ARM helper/report and do not infer a production defect or source fix from a harmless demonstrated EOL transform alone.
