# A19 — Winds recipes and actual-patch behavior

**PASS for this bounded review; no concrete blocker found.** All 14 Winds recipes were inspected, and five complete factory patches were measured across register, velocity, channel pressure, release, and quality. This is numerical/source review, not a listening assessment or a claim of acoustic equivalence. No production, test, shared-build, preset, or remote state was changed.

## Actual-patch results

Captures retain every authored parameter except the required quality selector. They use 48 kHz output, velocity 0.85 (soft comparison 0.30), a channel-pressure step from zero to 0.8 at 1.2 s, note-off at 3 s, and a one-second tail. Calls use 113-frame blocks shortened exactly at event boundaries. Engine telemetry confirms 2× realtime and 8× HQ/offline.

All samples are finite. The maximum absolute peak across the entire set is **0.098132**. None of the 15 tested register/patch combinations is silent. Settled fundamentals match the authored footage within **0.341 cent** with original drift/dispersion still active. Clarinet's upper-harmonic odd/even power changes from **+13.65 dB at MIDI 48** to **−1.85 dB at MIDI 72**, consistent with its explicitly programmed register transition; it is not a fixed odd-only oscillator.

Middle-register response, realtime 2×:

| Patch / input note | Velocity 0.85 vs 0.30 | Pressure 0.8 vs zero | Release to −60 dB relative to held RMS |
|---|---:|---:|---:|
| Flute / 72 | +7.465 dB | +2.679 dB | 140 ms |
| Clarinet / 60 | +7.061 dB | +3.891 dB | 130 ms |
| Oboe / 72 | +8.439 dB | +4.952 dB | 140 ms |
| Bassoon / 60, sounding 48 | +7.222 dB | +4.202 dB | 140 ms |
| Shakuhachi / 60 | +7.018 dB | +3.218 dB | 180 ms |

All five show increased spectral centroid with both velocity and pressure. HQ changes the measured velocity gain by at most **0.00794 dB** and pressure gain by **0.00263 dB**. Samples before the pressure event exactly equal their unpressured controls. Across all register tests, the release result is **130–180 ms**, identical between qualities at the 10 ms analysis resolution. Every current capture's final 100 ms is below **−178 dBFS**. These measured thresholds are not the same quantity as the authored envelope time parameters.

### Realtime versus HQ texture

Across all 15 register/patch pairs, HQ minus realtime sustained off-harmonic power is **−0.15055 to +0.13018 dB**. A wider harmonic exclusion gives a maximum absolute difference of **0.32870 dB**. Whole-output RMS differs by at most **0.21432 dB**, and settled pitch differs by at most **0.00078 cent**.

The complete-patch comparison exposes the earlier loss most clearly in the double reeds:

| Middle-register patch | .6 HQ minus realtime off-harmonic power | .7 HQ minus realtime off-harmonic power |
|---|---:|---:|
| Flute | −0.113 dB | −0.114 dB |
| Clarinet | −1.622 dB | +0.038 dB |
| Oboe | −5.647 dB | −0.027 dB |
| Bassoon | −5.408 dB | +0.130 dB |
| Shakuhachi | −0.206 dB | −0.037 dB |

The source-based interpretation is that the flute recipes' independent circuit-air contribution makes the body correction less visible in this complete-output measure. Do not interpret their smaller change as an absent body correction: A10's isolated integration fixture addresses that different question. Likewise, whole-output RMS barely changes between .6 and .7 HQ (less than **0.00007 dB** here), despite restoring over 5.5 dB of the measured Oboe/Bassoon residual texture.

**All five current realtime middle-note captures exactly equal their .6 PCM. All five offline captures exactly equal explicit HQ PCM.** The compatibility claim is limited to these exact captures.

## Method, reproducibility, and limits

From the repository root:

```sh
python3 docs/preset-evidence/2026.11.7/verification/a19/reproduce.py --work /tmp/cs80-a19
```

The script exports **all matching headers** with `git archive` for each frozen source, links separate probes against the supplied .6/.7 archives, captures PCM under `/tmp`, independently exports the current inventory, and writes compact evidence here. Add `--rebuild --work /tmp/cs80-a19-rebuild --output /tmp/cs80-a19-rebuild/evidence` to compile both cores from their frozen sources instead of using the supplied archives. [provenance.json](../verification/a19/provenance.json) retains exact compiler/link commands, compiler identity, source/header/library/executable hashes, and source commits. Capture hashes, actual quality factors, individual metrics, and pairwise results are retained alongside [measurements.json](../verification/a19/measurements.json).

Sustained analysis uses 2.0–2.9 s: stereo RMS, and mono Hann-weighted normalized spectral power from 1–12 kHz excluding ±20 Hz about harmonics of the measured fundamental. The ±40 Hz cross-check is omitted for Bassoon MIDI 48, where 40 Hz exclusions overlap at its 65.4 Hz fundamental. Full-patch off-harmonic power includes circuit air and modulation residuals; it is not an isolated breath-level or perceptual similarity score. Release measures the final 10 ms RMS window above held power × 10⁻⁶. No clips were listened to. No claims are made for unrendered programs, other host rates, performance timing, or exhaustive polyphonic/legato behavior.
