package availability is not a pass. Its signing status says the helper did not
inspect signing or perform release signing/notarization. Mac AU ad-hoc
registration signing is not publisher signing or notarization. Original
directory comparisons establish ordinary file bytes; they do not prove
ACLs, xattrs, ownership or signature validity. The Mac VST3 source-path sequence
is not an independent tree hash. A57 does not turn header checks into a real
installation, named-DAW compatibility or listening result.

[A42](a42.md) and [A43](a43.md) remain authoritative for the user flow:
**Factory LOAD/RELOAD is not a complete session reset.** It applies the current
factory sound controls and PANEL sources while retaining physical setup and
separate modern configuration; automation can subsequently write controls.
Use a fresh instance for the initial comparison, explicitly load the factory
entry, and play fresh notes. Old sessions, user patches and A/B states can keep
earlier stored controls even when the displayed name looks like a factory
program.

Source-time guides deliberately retain pending qualification language and
historical `.4` download records. Exact source correspondence is correct;
final online publication and the live download pointer remain separate work.
The current external-validator requirement is **15 lanes**: Linux 3, Windows 2,
ARM Mac 5 and Intel Mac 5. The frozen A41 helper's historical “13” prose is not
the current gate roster and has not been edited.
