## Formal capability skips

Both platforms formally skip exactly `cs80_filter_batch_cap_tests` and
`cs80_stereo_pra_exact_tests`. Their JUnit elements are `status="notrun"` with
`SKIP_RETURN_CODE=77`, and original consoles independently say `***Skipped`.
LastTest's `Test Passed.` representation for these cases is retained but is not
interpreted as capability execution.

The frozen CMake registration assigns return code 77 to both tests. The filter
batch test first validates its fixture, then explicitly prints “AVX2 unavailable
or disabled; no SIMD qualification” when kernel selection is null. CMake
disables that backend for non-GNU compilers, and its exact-build header excludes
Clang/MSVC and requires the supported x86_64/FP contract. Original compiler logs
identify AppleClang 17.0.0.17000013 on ARM and MSVC 19.44.35230.0 on Windows.

The exact stereo PRA test only compiles its substantive branch for the complete
Linux x86_64 GCC 14.2 optimized strict-FP specialization. Its other branch returns
77 without text. ARM macOS and Windows cannot enter that branch. Neither SIMD
nor specialized PRA execution is qualified by these skips. Frozen source hashes
and predicates are retained in the
[source review](../verification/a53/source-predicate-review.json).
