# A27 — Init entries and older saved controls

**Pass within the core scope.** Both Init entries preserve their addresses and
every published control. Fresh deterministic captures are exactly unchanged
against `.6` and published `.4` in all 12 cases. No preset was added or edited.
Saved-state defaults and factory reload are distinct operations; this review
does not claim that an old body-enabled sound renders identically after an
engine correction.

## Saved controls and defaults

`ParamValues` initializes every field from `paramDef(i).def`. The core accepts a
completed, fixed-size vector: `Engine::applyParams` preserves finite in-range
values, clamps finite out-of-range values, and replaces nonfinite values with
declared defaults. It does not deserialize an old session or look up its named
factory recipe. The [direct core check](../verification/a27/core-completion.json)
passes **114 checks**, including edited saved controls, replacement of stale
receiving controls, these five completed-prefix cases, and all 14 body controls'
nonfinite/range boundaries:

| Older stored control set | Completion for absent body fields |
| --- | --- |
| 190 controls, before bodies | Model 0, mix 0, brightness 0.5, decay 1, size 1, variant/material 0 on both ranks |
| 198 controls, first eight body controls | Preserve those eight; size 1, variant/material 0 |
| 200 controls, including size | Preserve those ten; variant/material 0 |
| 202 controls, including variants | Preserve those twelve; material 0 |
| 204 controls | Preserve all fourteen |

This executable check supplies the completed vectors directly; it is **not a
host deserialization test**. The actual loader behavior is source-reviewed:
`PluginProcessor.cpp::normaliseRestoredState` completes a detached tree before
APVTS replacement, preventing missing children from inheriting the receiving
instance's live values. The last duplicate child wins; missing/nonfinite values
use fallbacks, and host ranges clamp/snap legal values. Present valid musical
values remain stored values. Exceptions are explicit: retired policy fields
become `sourcePerformance=1` and `parityMode=0`; missing/invalid Original SUB
mode restores to 0, although fresh `ParamValues` defaults it to 1.

Inactive A/B restoration in `PluginProcessorLibrary.cpp` likewise supplies
declared defaults for absent body fields and retains present body values. Its
generic fallback is the declared default; the main session loader's special
Original SUB fallback must not be generalized to every reader.
`PresetFileValues.h` is a preview/edit-reference reader and expressly does not
replace full schema migration. These relevant state sources are unchanged
from `.6` (receipt lists and hashes them).

`setStateInformation` restores saved values and metadata without invoking a
factory recipe. `PresetBrowser::loadEntry`, including the button relabelled
RELOAD, invokes `loadFactoryPreset` for factory entries, which applies the
current bank vector. Thus saved edits survive session restoration, whereas
factory LOAD/RELOAD intentionally applies the current recipe. `.7` retains the
`.6` recipe vectors; cumulative recipe changes since `.4` apply when recalled.
An older body-enabled saved patch still runs the current body implementation,
so the `.7` piano, noise, string-formant or low-choir corrections can change its
audio even when its saved controls are unchanged.
