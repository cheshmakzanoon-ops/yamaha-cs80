# Reproduce A17

Run from the repository root. `render.py` uses the two explicitly supplied capture binaries and writes all WAVs to `/tmp/cs80-a17-1cee5a`. Create current/baseline inventory JSONs there with each binary's `--inventory` option. Compile `contact.cpp` once with current `-I src` and `/tmp/cs80-build-1cee5a/libcs80_core.a`, and once with **18711f93 archived full `src` headers** and `/tmp/cs80-reference-1cee5a/libcs80_core.a`; use `c++ -std=c++20 -O2 ... -lpthread`. Run them with output arguments `/tmp/cs80-a17-1cee5a/contact-current-pcm` and `.../contact-baseline-pcm` respectively.

Compile header-only `contact_component.cpp` twice against those matching header trees. Redirect stdout to `component-current.csv` and `component-baseline.csv` in this evidence directory. This diagnostic exposes private state solely to set modal count to zero after note-on: it retains the real contact generator, rather than changing production source or recipes. It averages 20-ms noise-only RMS across 128 deterministic seeds at 96/384 kHz internal rates; both actual Agogo body parameter sets are checked. It is explicitly not a complete-patch render.

Run `analyze.py` after the captures. It requires NumPy and SciPy, writes the compact inventory, matrix, results and binding evidence, and compares all 23 complete inventory entries to baseline. No WAV/PCM is stored in the repository. The report's dBFS values are measured stereo RMS, with −300 dB representing the reporting floor for silence. Spectral identities use Hann-window projections around each modeled target in 1-cent steps, not a perceptual fundamental estimator. All full-patch renders retain factory levels and effects without normalization. The source/binary hashes in `binding.json` identify the specific reviewed development snapshot.
