## Why the final audio composition is justified

The full A33 comparison belongs to source `6094bce`, after the first 17 level
corrections. It contains 523 matched main captures. The later 09af change alters
exactly two binary32 control values: `volume` for **Golden Pads 66** at host
index 109 and **Cathedral Pad** at host index 303. Both become 0.650. Across all
523 × 202 values, every other value is identical, and every non-value program
field is unchanged between the 6094 and final inventories.

I independently read both retained core archives and checked every member.
`Engine.cpp.o`, `EngineWscHeld.cpp.o` and `Ig00156Batch.cpp.o` are byte-identical.
Only `FactoryPresets.cpp.o` differs, matching the two preset-level edits. The
current core archive and capture executable also match the separately retained
post-correction hashes. The capture implementation itself is byte-identical
from the frozen baseline through c76.

Each call to `render()` creates a new Engine, prepares it, submits the complete
parameter vector and plays the explicit gesture. It does not reuse the previous
program's sounding voice or effect state. The stable initialization/seed code
is in the unchanged Engine objects. Thus the two changed earlier bank entries
do not introduce an unexamined state-carryover dependency for later captures.

baseline WAV and PCM hashes, settings, frames and baseline measurements equal

## Playing-response changes are not spectral-quality scores

A raw PCM difference can arise from level alone. An equal-RMS residual can
arise from timing, phase, envelope, modulation or spectral changes. The
Hellinger measure describes an averaged spectral distribution for one held
interval. None is a score of realism or listening preference, and the two
thresholds above are descriptive counts.

Noise Pad, Ether Pad and Sub Bass are close to gain-only changes at the main
0.8-velocity gesture. Their separate soft/firm evidence therefore matters. I
checked all six complete vectors embedded in A33's common-master diagnostic
against the final or zero-extended baseline inventories. They match at binary32
precision. The source explicitly sets both master volumes to 0.5 and uses one
Engine implementation. All six retained contrasts agree with the separate
complete-patch measurements within 0.00000002 dB:

| Program | Previous soft/firm contrast | Revised contrast |
| --- | ---: | ---: |
| Noise Pad | 3.095326 dB | 6.915161 dB |
| Ether Pad | 2.649972 dB | 6.821344 dB |
| Sub Bass | 7.454694 dB | 9.381205 dB |

This supports a playing-response change beyond the output trim. It does not
justify claiming a wholesale spectral redesign of those three voices or
indistinguishability from a physical instrument.
