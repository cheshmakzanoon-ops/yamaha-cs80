# A07 — struck-body dynamics correction

Baseline: `8685e9ed39d6347b67401da7590b7e1e8e95472d` / factory revision 2026.11.4.

## Change

Piano, reed EP, clavichord, nylon/steel/plucked-bass and mallet bodies now normalize against their **full-strike spectral bound**, evaluated at the same note, body geometry, initial color, modal coverage and pluck position. Previously each quieter strike normalized its own smaller overtone sum, boosting its fundamental and compressing the dynamic response supplied by the external rank VCA.

The bound is calculated while authoring modes at note onset. It adds no per-sample work, storage, random draws or second oscillator bank. It does not change frequencies, phases, decay coefficients or color-dependent spectral ratios. Tine retains its already-correct bound. Sustained bodies and fixed-touch harpsichord retain their existing normalization.

## Rendered evidence

The identical new `StruckBodyDynamicsTests.cpp` test source was compiled against both headers with GCC 14.2.0, `-std=c++20 -O2 -Wall -Wextra -Wpedantic`:

| Source | Checks | Failures |
|---|---:|---:|
| Baseline 2026.11.4 | 3,439 | 1,335 |
| Corrected body | 3,439 | 0 |
| Existing `InstrumentBodyTests.cpp`, unchanged | 2,077 | 0 |

Coverage includes all eleven touch-sensitive struck bodies, host rates 44.1/48/96 kHz, bass/middle/treble registers, four velocity points, dark/bright endpoints, geometry/decay endpoints, fundamental and RMS monotonicity, and gain-independent spectral contrast. Additional boundary renders include MIDI 0 and 127. The unchanged body suite generated 41,062,350 samples.

For the following isolated-body measurement, host/internal rates are 48/96 kHz, MIDI note 60, velocities 0.2 and 0.9, brightness 0.65, decay/size 1, seed `0x7812a3`. The DFT/RMS window is 40–300 ms. Values are firm-minus-soft RMS in dB, before the rank VCA:

| Body | Before | After |
|---|---:|---:|
| Piano | -0.074 | +0.930 |
| Reed EP | -0.598 | +1.405 |
| Bell | -2.016 | +0.300 |
| Vibraphone | -0.790 | +0.028 |
| Marimba | -1.639 | +0.062 |
| Celesta | -2.093 | +0.223 |

The old soft-strike fundamental boost was +0.820 dB for piano, +0.714 dB for reed, +2.316 dB for bell/celesta, +0.818 dB for vibes and +1.702 dB for marimba. Corrected piano and reed fundamentals increase with excitation; the mallet fundamentals stay level to measurement precision. Existing gain-independent spectral contrasts are retained, so these results are not a claim that a gain increase alone improves timbre.
