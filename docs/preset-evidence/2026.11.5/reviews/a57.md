## Prepared bounded public probe

The [streaming probe](../verification/a57-probe-public-artifact.py) accepts an
explicit source, run, attempt, expected artifact name and authenticated API
files. It checks internal repository/source/run/size/digest/expiry context,
constructs the exact public URL from the actual ID, follows HTTPS redirects,
and hashes the complete response without retaining another large archive copy.
It requires HTTP 200, no partial Content-Range, and exact API size and SHA-256.
It rejects a body exceeding the expected length; metadata and artifact size
are bounded. Outputs must be fresh.

This reusable helper is **syntax-checked only at this checkpoint**. The actual
historical requests above were separately executed with the standard HTTPS
client. The helper has not been run against current product artifacts.

Its successful result can establish `public_route_verified` for one actual
artifact at the observation time. It deliberately retains
`artifact_attempt_binding_verified: false` and `release_qualified: false`:
metadata authenticity, original upload/attempt identity, complete contents and
native/pluginval results are separate gates. Full response equality is an
independent public-access observation, not proof of those other outcomes.
