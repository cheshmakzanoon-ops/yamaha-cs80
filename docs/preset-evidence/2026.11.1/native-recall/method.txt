and relevant source hashes are in `summary.json`.

## Storage and display conditions

The successful runs unset `DISPLAY`, set `JUCE_FONT_PATH` to the installed
DejaVu font directory, redirect `XDG_CONFIG_HOME` and `CS80_FAVOURITES_FILE`
inside this diagnostic directory, and use the fixture's existing temporary
directories for preset writes. These selected fixtures do not require native
window peers. No source or acceptance condition was changed.

An initial attempt through the provided sysroot `xvfb-run` printed 2,355 checks
and zero failures but returned 1. The same wrapper returned 1 for `/bin/true`:
Xvfb could not bind any local/unix listening socket, and wrapper cleanup failed
to kill its already exited server. The raw first attempt and `xvfb-true.log`
are preserved. That attempt is not counted as a successful test execution.

## Reproduction

Build the current `CS80Snapshots` Release target, then run:

```sh
python run-native-recall.py --repo /path/to/yamaha-cs80 \
  --binary /path/to/yamaha-cs80/build-native/CS80Snapshots_artefacts/Release/CS80Snapshots \
  --out /path/to/new-native-recall-output
```

`run-results.json` and the four raw logs preserve the observed run. The replay
script records each child exit status and fails if any count is missing, any
assertion fails, or any child exits unsuccessfully.
