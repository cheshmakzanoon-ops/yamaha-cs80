# Oscillator rolling-endpoint evaluation

The full preregistered promotion criteria did not pass. The production oscillator remains unchanged. This does not establish zero effect, an audible change, or a universal regression.

The preregistered, balanced native Linux VST3 comparison estimates a **+5.45% Circuit callback CPU reduction**, 95% block-bootstrap interval **[-2.18%, +9.88%]**, versus a **7.41%** claim floor. Negative values mean the candidate took longer. This was a fixed 16-note input cohort at 48 kHz and 64-frame blocks, not a DAW meter or evidence of satisfying the product CPU budget.

All 108 untimed configurations matched complete recorded render observations and saved post-A component state. The [full measured result](../experiments/oscillator-rolling-endpoint/README.md) includes the two other policies, original candidate diff and adoption criteria, evidence archive, limitations, and a public arithmetic replay of all callback durations.
